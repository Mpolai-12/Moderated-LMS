# Moderated LMS — Lecturer User Manual

## 1. Purpose

This manual explains how lecturers use the Moderated LMS to create assignments, grant individual deadline extensions, review student submissions, and mark work.

## 2. Logging in

1. Start the LMS application.
2. Enter your username and password.
3. Your account must be active and have the Lecturer role.
4. After successful login, the Lecturer menu appears.

## 3. Lecturer menu

The menu provides these options:

1. Create assignment
2. Grant/update individual extension
3. View submissions
4. Mark submission / update mark
0. Log out

Enter the number of the operation you want to perform.

## 4. Create an assignment

1. Select **Create assignment**.
2. The system displays the courses assigned to you.
3. Enter the required Course ID.
4. Enter the assignment title.
5. Enter the assignment description.
6. Enter the deadline in UTC using this format:

   `YYYY-MM-DDTHH:MM:SSZ`

7. Enter the maximum mark. It must be greater than zero and no more than 1000.
8. The system confirms that the assignment has been created.

You can only create assignments for courses assigned to your lecturer account. If no courses are listed, contact the administrator.

## 5. Grant or update an individual extension

1. Select **Grant/update individual extension**.
2. The system displays assignments belonging to your courses.
3. Enter the Assignment ID.
4. The system displays student accounts.
5. Enter the student's user ID.
6. Enter the new deadline in UTC using the required date format.
7. Enter the reason for granting the extension.
8. The system confirms that the individual extension has been saved.

Important:
- The student must be enrolled in the assignment's course.
- The new deadline must be later than the original deadline.
- A reason is required.
- Granting another extension for the same student and assignment updates the existing extension.

The student's effective deadline is the individual extended deadline where one has been granted.

## 6. View submissions

1. Select **View submissions**.
2. The system displays submissions for assignments in your courses.
3. Review the displayed information:
   - Submission ID
   - Assignment title
   - Student name
   - Submission date and time
   - Submission state
   - Local file path or submission reference
   - Raw mark and maximum mark

A submission without a mark is shown as unmarked.

The LMS stores the student's local file path or submission reference. It does not upload or open the submitted file. Retrieve and inspect the work using the school's approved file-handling process.

## 7. Mark a submission or update a mark

1. Select **Mark submission / update mark**.
2. Review the list of submissions displayed.
3. Enter the Submission ID.
4. Enter the raw mark. It must be between zero and the assignment's maximum mark.
5. Enter written feedback. Feedback is required.
6. Enter the reason for the mark or mark change. This is required for the audit record.
7. The system saves the mark and confirms that it is awaiting HoD moderation.

Only submissions in your assigned courses can be marked. Submitted, late, and previously marked work can be marked.

Updating a mark sends it back for moderation. Any previous moderation or release status is reset.

## 8. Understanding the marking process

The lecturer records the raw mark and written feedback. The Head of Department (HoD) must then moderate the mark before it is released to the student.

A saved lecturer mark is not automatically visible to the student.

## 9. Important responsibilities

- Create assignments only for your assigned courses.
- Check assignment titles, descriptions, deadlines, and maximum marks before saving.
- Grant extensions only where appropriate and provide a clear reason.
- Review the correct student's work before entering a mark.
- Provide meaningful written feedback.
- Give a clear reason whenever a mark is entered or changed.
- Follow school procedures for handling student submission files.

## 10. Common problems

| Problem | What to do |
|---|---|
| No courses are listed | Ask the administrator to assign courses to your lecturer account. |
| You cannot create an assignment for a course | Check that the course is assigned to you. |
| The selected student is not enrolled | Ask the administrator to check the student's course enrolment. |
| Extension deadline is rejected | Ensure it is later than the original deadline and use UTC format. |
| Feedback or audit reason is rejected | Enter the required text before saving. |
| Submission cannot be marked | Check the Submission ID and ensure the submission belongs to one of your courses. |

## 11. Logging out

Select **0. Log out** when you have finished using the system.
