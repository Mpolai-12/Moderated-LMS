# Moderated LMS — Student User Manual

## 1. Purpose

This manual explains how students use the Moderated LMS to view assignments and deadlines, submit work, resubmit work where permitted, and view released marks and feedback.

## 2. Logging in

1. Start the LMS application.
2. Enter your username and password.
3. Your account must be active and have the Student role.
4. After successful login, the Student menu appears.

## 3. Student menu

The Student menu provides these options:

1. View enrolled assignments and deadlines
2. Submit / resubmit assignment
3. View released marks and feedback
0. Log out

Enter the number of the operation you want to perform.

## 4. View enrolled assignments and deadlines

1. Select **View enrolled assignments and deadlines**.
2. The system displays assignments for courses in which you are enrolled.
3. Review the displayed information:
   - Assignment ID
   - Course code
   - Assignment title
   - Original deadline
   - Effective deadline
   - Maximum mark
   - Submission state
   - Extension reason, if applicable

The effective deadline is the individual extended deadline where your lecturer has granted an extension. Otherwise, it is the original deadline.

An assignment that has not been submitted is shown with the state `NOT SUBMITTED`.

## 5. Submit an assignment

1. Select **Submit / resubmit assignment**.
2. Review the assignment list displayed.
3. Enter the Assignment ID.
4. Enter the local file path or submission reference for your work.
5. The system saves the submission and displays its state.

Important:
- You must be enrolled in the course containing the assignment.
- A submission path or reference is required.
- The LMS records the path or reference; it does not upload or copy your file.
- Keep your work in the location specified by your lecturer or school.

## 6. Resubmit an assignment

You may resubmit work only when:
- Your existing submission is still in `SUBMITTED` status.
- The effective deadline has not passed.
- The lecturer has not yet marked the submission.

To resubmit:
1. Select **Submit / resubmit assignment**.
2. Enter the Assignment ID again.
3. Enter the updated local file path or submission reference.
4. The system saves the new attempt and displays the attempt number.

Resubmission is not allowed after the effective deadline or after marking.

## 7. Understand submission states

| State | Meaning |
|---|---|
| `NOT SUBMITTED` | No submission has been recorded. |
| `SUBMITTED` | Work was submitted by the effective deadline. |
| `LATE` | Work was submitted after the effective deadline. |
| `MARKED` | The lecturer has entered a mark and feedback. |
| `MODERATED` | The Head of Department has moderated the mark. |
| `RELEASED` | The mark and feedback have been released for you to view. |

## 8. View released marks and feedback

1. Select **View released marks and feedback**.
2. The system displays marks that have been released to you.
3. Review the course, assignment, final mark, maximum mark, raw mark, late days, and written feedback.

Marks are visible here only after the lecturer has marked the work and the Head of Department has moderated and released the result.

If no marks have been released, the system displays a message indicating that there are no released marks.

## 9. Late submission penalties

The LMS calculates a late penalty using the assignment's maximum mark:

- A deduction of 10% of the maximum mark applies for each late day.
- The deduction is applied for up to three late days.
- A submission more than three days late receives a final mark of zero.
- An approved individual extension changes the effective deadline used in the calculation.

The displayed final mark may therefore be lower than the lecturer's raw mark.

## 10. Important responsibilities

- Check assignment instructions and deadlines regularly.
- Use the effective deadline shown by the system.
- Submit work using the correct file path or submission reference.
- Keep a copy of your submitted work.
- Resubmit before the effective deadline if you need to replace your submission.
- Contact your lecturer if you believe an extension or submission record is incorrect.
- Check the system for marks and feedback after results have been released.

## 11. Common problems

| Problem | What to do |
|---|---|
| No assignments are displayed | Contact the administrator to check your course enrolment. |
| Assignment ID is not accepted | Check the ID in your assignment list. |
| Submission path is rejected | Enter a non-empty local file path or submission reference. |
| Resubmission is not allowed | Check whether the effective deadline has passed or the work has already been marked. |
| No marks are displayed | Wait until the lecturer marks the work and the HoD releases the result. |
| Your extension is not reflected | Contact your lecturer to check the individual extension. |

## 12. Logging out

Select **0. Log out** when you have finished using the system.
